This directory is a source-identical snapshot of the AOWIS-SERVER-MODEL
unit registry (`include/aowis/model/units/`) from the accompanying desktop GUI
snapshot, licensed Apache-2.0 (see root LICENSE).

Only the three header-only unit metadata/profile definitions are included.
Mobile uses these authoritative unit IDs, predefined profiles, inheritance
rules, and option lists until a pinned MODEL dependency is available in the
Linux and Android toolchains. Do not edit or diverge these headers here.
